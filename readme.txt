RISC-V Assembler & Simulator (RV32I)
Overview

This project implements a custom Assembler and Simulator for a subset of the RV32I (RISC-V 32-bit integer) instruction set.

The assembler converts assembly code into 32-bit binary instructions, and the simulator executes those instructions by updating registers, memory, and the program counter (PC).

Components

SimpleAssembler
→ Converts RISC-V assembly instructions into 32-bit binary machine code
→ Handles labels, immediates, and syntax checking

SimpleSimulator
→ Executes binary instructions generated by the assembler
→ Updates registers, PC, and memory
→ Generates execution trace and memory dump

AutomatedTesting
→ Contains test cases and grading scripts

Features
Converts assembly to 32-bit binary
Supports RV32I instruction subset
Handles labels and PC-relative addressing
Detects syntax and instruction errors
Simulates execution step-by-step
Outputs register trace and memory state
